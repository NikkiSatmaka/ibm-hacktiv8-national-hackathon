# Example result

Exact wording and URLs vary. A successful run creates a document, returns its URL, and reports email/calendar actions.

```text
Project Omega Weekly Meeting
SUMMARY
The team reviewed prototype delivery and assigned presentation and integration-testing work.
DECISIONS
• The prototype must be finished by September 10.
ACTION ITEMS
• Prepare the presentation — Owner: Sarah — Deadline: Not specified
• Test the Langflow integration — Owner: Andi — Deadline: Not specified
NEXT MEETING
• Date: September 8, 2026
• Time: 10:00 AM
```

The first meeting in `meeting-notes-example.md` should produce a document, email to explicitly listed placeholder participants, and calendar event. Later notes omit required details, so the agent must not invent them.
