Artificial Intelligence, or AI, refers to computer systems designed to perform tasks that normally require human intelligence.

Examples of AI capabilities include:

- Understanding natural language
- Recognizing images
- Making predictions
- Generating text or images
- Recommending actions

AI is a broad field. Machine Learning is one approach used to build AI systems.
Traditional software usually follows rules explicitly written by programmers. Machine Learning systems instead learn patterns from data.

Example:

- A traditional spam filter might use manually written rules such as blocking emails containing certain words.
- A Machine Learning spam filter can learn patterns from many examples of emails that have already been labeled as spam or not spam.
- AI systems should not automatically be trusted simply because they produce confident answers. Their outputs should be reviewed when they are used for important decisions.
